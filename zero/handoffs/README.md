# Handoffs

A handoff lives at:

    zero/handoffs/YYYY-MM-DD-<agent>.md

`<agent>` is the writer, one word, lowercase: jarvis, cursor, claude, or christian.

One writer per file. A reply is a new file, dated the day it is written. Do not
edit a file someone else wrote.

Every handoff names its intent, INT-nnn, or says "no INT yet, propose one".

Nothing in this directory runs. No timer, no daemon, and no tool reads it on
its own. v1 is by hand.

The fields, the allowed values, and the approval phrases are in
zero/orchestration/PLAYBOOK.md.

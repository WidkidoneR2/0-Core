# 🌲 faelight-release

**Version:** 1.0.3 &nbsp;|&nbsp; **License:** - &nbsp;|&nbsp; **Status:** active &nbsp;|&nbsp; **Category:** release

## 📖 Description

The forest publishes itself -- plan, preview, and cut releases as bootable, rollback-safe generations.

---

## 📝 Changelog

## 🌱 1.0.0
- 🌲 NixOS-native release manager: cuts a release as a bootable generation with a full rollback point.
- ✨ `plan` -- dry-run a release, seeing exactly what will happen before anything is published.
- ✨ `preview` -- see the auto-generated changelog for the next version.
- ✨ Release triad tracking: version ↔ generation ↔ commit, recorded so a release generation is never lost to garbage collection.
- ✨ `rollback` -- return to any previous release generation.
- 🌲 Cuts the inaugural **Faelight OS 1.0.0 "Morphwood"**.

## Earlier
- ⚙️ Release ceremony foundation: changelog generation, generation snapshots, version stewardship.

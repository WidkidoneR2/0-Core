# Faelight Browser v0.1.0

A web browser built on 0-Core principles.

## Philosophy

- **Security through transparency**: Every network request visible
- **Intent over automation**: Nothing happens without user consent
- **Recovery over perfection**: Crash? Resume exactly where you left off
- **Comprehension over convenience**: User understands what's happening

## Features (Planned)

- [ ] Phase 0: Foundation (structure + colors)
- [ ] Phase 1: Wayland UI (tab bar, address bar, status bar)
- [ ] Phase 2: Storage (bookmarks, history, sessions)
- [ ] Phase 3: Servo integration (actual web rendering)
- [ ] Phase 4: Security (permissions, audit log, certificates)

## Build
```bash
cargo build --release
```

## Run
```bash
cargo run
```

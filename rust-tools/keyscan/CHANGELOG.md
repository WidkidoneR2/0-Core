# Changelog - keyscan

## [3.0.0] - 2026-02-11

### 🎉 PRODUCTION READY - SWAY KEYBIND INTELLIGENCE

**Features:**
- Conflict detection (default mode)
- Complete keybind listing
- Statistics and analytics
- Search/filter keybinds
- Category grouping
- Markdown cheatsheet generator
- Unused combo suggestions
- Health check integration

**Commands:**
- `(default)` - Check for conflicts
- `--list` - List all keybindings
- `--stats` - Show statistics
- `--find PATTERN` - Search keybindings
- `--category` - Group by category
- `--cheatsheet` - Generate markdown
- `--suggest` - Suggest unused combos
- `--health` - Health check

**Analysis:**
- Modifier usage tracking
- Key usage patterns
- Category distribution
- Conflict detection
- Binding normalization

**Categories:**
- Window Management
- Workspace Control
- Application Launch
- System Control
- Media Control
- Custom

**Code Quality:**
- 547 lines of analysis code
- Zero clippy warnings
- Clean parsing logic

**Integration:**
- Reads Sway config
- Part of Faelight Forest
- Health check support

# Changelog - get-version

## [4.0.0] - 2026-02-11

### 🎉 PRODUCTION READY

**Features:**
- Get system version from VERSION file
- Get package version from .dotmeta
- Health check integration (`health` command)

**Commands:**
- `system` - Show system version (default)
- `package <name>` - Show package version
- `health` - Run health check

**Code Quality:**
- Clean 114 lines
- Zero clippy warnings
- Simple, focused utility
- Clear error messages

**Integration:**
- Uses faelight-core paths
- Part of 0-Core ecosystem

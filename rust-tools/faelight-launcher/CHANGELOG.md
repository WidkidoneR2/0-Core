## [4.0.0] - 2026-02-11

### 🎉 Production Ready

**Comprehensive Documentation:**
- 151-line README with usage guide
- Installation instructions
- Keyboard shortcuts table
- Technical details section
- Comparison with Walker/Rofi
- Examples section
- CHANGELOG.md added

**Code Quality:**
- Zero clippy warnings
- Workspace-wide quality improvements
- Proper error handling
- Health check support

**Features:**
- XDG desktop entry scanning
- Fuzzy search with recency scoring
- File search mode
- Icon rendering (SVG/PNG)
- Wayland-native rendering
- Faelight Forest theme integration
- Sub-50ms startup time

### Technical
- Lines of code: 1,668
- Dependencies: smithay-client-toolkit, rusttype, faelight-core
- Memory usage: ~8MB base

## The Core Insight
v12 Strategy proposes. You decide.

This is not automation for its own sake.
This is the forest earning the right to act through demonstrated
accuracy, transparency, and alignment with your values over time.

v13 does not act without a mandate.

## What Autonomy Means in Practice

### Authorized Actions (examples)
```bash
# Human defines mandate once:
core mandate set "auto-checkpoint before major changes"
core mandate set "auto-run security scan weekly"
core mandate set "suggest retire tools with 0 usage for 30 days"

# Forest acts within mandate:
# "I am checkpointing because you are about to modify 5+ files"
# "Running weekly security scan (authorized: auto-run)"
# "faelight-fetch has 0 uses in 45 days — retire? (mandate: suggest)"
```

### Hard Boundaries (never crossed)
```
Never commit without human confirmation
Never delete files without explicit command
Never modify core config without unlock
Never act outside defined mandate
Never bypass human authorization on destructive actions
```

## The Five Pillars

### Pillar 1 — Mandate System
Human-defined authorization boundaries.
```bash
core mandate list        # what is the forest authorized to do?
core mandate set <rule>  # authorize a new action type
core mandate revoke <id> # remove authorization
core mandate history     # what has the forest done autonomously?
```

### Pillar 2 — Autonomous Action Engine
Execute authorized actions with full transparency.
Every autonomous action is logged, explained, and reversible.
```bash
core autonomy run        # execute pending authorized actions
core autonomy pending    # what actions are queued?
core autonomy explain    # why did the forest take this action?
core autonomy revert     # undo the last autonomous action
```

### Pillar 3 — Trust Calibration
The forest earns autonomy through demonstrated accuracy.
```bash
core trust score         # current trust score per action type
core trust history       # accuracy of past autonomous actions
core trust expand        # request expanded autonomy (human approves)
```

### Pillar 4 — Transparency Layer
Every autonomous action is visible and explained.
No silent operations. No hidden state changes.
```bash
core autonomy log        # full log of all autonomous actions
core autonomy audit      # third-party verifiable action record
```

### Pillar 5 — Revocation System
Human can revoke any mandate instantly.
One command returns the forest to fully manual operation.
```bash
core mandate revoke-all  # return to fully manual mode
core mandate pause       # temporarily suspend autonomy
```

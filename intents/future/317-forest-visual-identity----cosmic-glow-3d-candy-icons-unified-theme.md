## Why This Intent Exists

The forest tools work. Now they need to look like they belong together.
faelight-fm v2 set the bar. Every tool needs to match it.

The vision: a unified visual identity where every faelight tool --
terminal, bar, menu, lock, compositor -- shares the same design language.
Forest green. Glowing accents. 3D candy-style icons. Depth and warmth.

---

## The Visual Stack

**Colors (already established):**
- Background: forest green #11140f
- Foreground: #d7e0da
- Accent: glowing green highlights
- Selection: gold

**New additions:**
- 3D candy-style icons for all tools
- Subtle glow effects on active elements
- Depth: shadows, layering, visual hierarchy
- Consistent border radius and spacing across all tools
